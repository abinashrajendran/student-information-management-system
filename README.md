### Project Overview
A Full-Stack Web Application built to manage student records with complete CRUD operations, department analytics, and an interactive REST API playground.

### Tech Stack
- **Frontend:** React 19, TypeScript, Tailwind CSS
- **Backend:** Node.js, Express.js REST API
- **Deployment:** Google Cloud Run

### Features
- Complete CRUD (Create, Read, Update, Delete) Student Records
- Department & Status Filtering with GPA Sorting
- Live REST API Testing Playground (GET, POST, PUT, DELETE)
- Real-time Validation & Response Logs
